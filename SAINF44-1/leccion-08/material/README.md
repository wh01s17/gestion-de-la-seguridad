# Fuentes internas del caso - Lección 08

Esta carpeta conserva los datos sintéticos usados para construir y revisar la actividad de la Lección 08. **No se distribuye al estudiante.**

El estudiante recibe únicamente `../actividad-leccion-08.md`, que ya contiene los antecedentes obligatorios junto a cada consigna.

## Inventario y uso

| Archivo | Uso interno |
| --- | --- |
| `contexto-organizacional.md` | Perfil original recibido antes de la Lección 07. Su sección de carencias es histórica. |
| `estado-consolidado-l07.md` | Estado vigente al comenzar la Lección 08: alcance, escala, tolerancias y propietarios. |
| `criterios-de-riesgo-l07.md` | Detalle y reglas de la escala común. |
| `fichas-referencias.md` | Fuente para las fichas breves de ISO/IEC 27005, NIST SP 800-30, NIST CSF 2.0 e IR 8286A. |
| `necesidades-de-decision.csv` | Fuente de las seis filas incorporadas en el Paso 1. |
| `evaluaciones-previas.csv` | Fuente de la ampliación opcional sobre escalas incompatibles. |
| `propuestas-tratamiento.csv` | Fuente de la ampliación opcional sobre opciones de tratamiento. |
| `manifest_entrega.sha256` | Control interno de estas fuentes, no actividad estudiantil. |

## Regla de actualización

Cuando cambie una fuente:

1. actualice el bloque correspondiente de `../actividad-leccion-08.md`;
2. actualice la solución docente;
3. revise que el estado consolidado no contradiga el contexto histórico;
4. regenere el manifiesto interno.

No vuelva a separar los antecedentes en archivos que el estudiante deba consultar durante cada paso. Los CSV y las fichas completas existen para mantenimiento y trazabilidad; la actividad es la única fuente de trabajo estudiantil.
